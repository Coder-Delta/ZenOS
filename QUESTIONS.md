# Questions and Support

Questions are welcome.

ZenOS is an experimental operating-system project, and contributors may have different levels of systems-programming experience.

## Before Asking

Check:

1. `README.md`
2. `docs/`
3. Existing Issues
4. Existing Pull Requests
5. Existing Discussions

Your question may already have an answer.

## Ask Focused Questions

Instead of:

```text
It doesn't work. Help?
```

Provide:

```text
I am trying to boot the kernel using QEMU.

Command:

<command>

Expected:

ZenOS should start the shell.

Actual:

QEMU exits after the kernel starts.

Error:

<error>

Environment:

Fedora
x86_64
QEMU <version>
```

## Include Relevant Information

When asking technical questions, include:

* What you are trying to accomplish.
* What you tried.
* The command you used.
* The error message.
* Your environment.
* What you expected to happen.

## Beginners

Beginners are welcome.

If you are learning operating-system development, you can start with:

* Linux basics
* C programming
* Git
* Shell scripting
* Computer architecture
* Operating-system fundamentals
* Linux kernel concepts
* QEMU

## Good Places to Ask

Use the project's available:

* GitHub Issues
* GitHub Discussions
* Pull Request discussions
* Community channels

Use Issues primarily for reproducible bugs and actionable project tasks.

## Avoid

Do not post:

* Passwords
* API keys
* Private credentials
* Sensitive personal information
* Unrelated spam

## Helping Others

If you know the answer to another contributor's question, consider helping them.

A useful answer should explain the reasoning rather than simply providing a command.
